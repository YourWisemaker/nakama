AI agents that work with your team.

ChatGPT-simple to use. Full agent capability underneath. Built for organizations from day one.

Ahmad Rosid · Demo · Cloud · Open source

Problem

Everyone uses ChatGPT. None of it belongs to the team.

The company shares the work. Each person keeps their own chats.

  1. 1
    Work is copied, not shared Two people on the same task each start a new chat, paste the same files, and get different answers.
  2. 2
    What the AI learned walks out the door Useful context sits in one person’s history. When they leave or switch tools, the team starts over.
  3. 3
    Nobody can set the rules There is no company agent with a role. You cannot give one assistant tools and keep another read-only.

Why it fails

Today you pick easy, or you pick powerful. You cannot pick both for a team.

ChatGPT and Claude

  • Anyone can open a tab.
  • A Team plan is still separate chats.
  • No shared company agent with its own tools.
  • Does not live on Telegram or WhatsApp.

OpenClaw and Hermes

  • They can actually do the work.
  • Installed on one laptop, for one person.
  • Setup is heavy.
  • A teammate cannot just sign in.

Solution

Nakama is that capability, built as a team product.

A dashboard that feels like ChatGPT. Agents with tools, skills, memory, and channels. Orgs, roles, and isolated profiles from day one.

Product

One server. Many orgs. Agents that can act.

1

Chat

A familiar web dashboard. Same agent on CLI, Telegram, WhatsApp, and Discord.

2

Act

Each profile has identity, tools, skills, and memory. Not a disposable thread.

3

Isolate

Orgs are tenants. Profiles stay separate. Permissions stay explicit.

Isolation

One agent can be narrow. Another can be fully capable.

  • Roles: admin, member, viewer. Viewers read. They do not invoke agents.
  • Profiles: identity, tools, memory, and permissions per agent — not one shared bot for the whole company.
  • Tenants: one install can serve many orgs. Client workspaces do not mix.

Why now

Agents are leaving the chat box. Teams need a product, not a personal CLI.

Tools and skills

Agents now search, code, browse, and call apps. A private chat cannot govern that.

Channels

Work already happens on Telegram, WhatsApp, and Discord. The agent has to live there too.

Team demand

Companies want shared agents with roles. Operator setups still assume one person, one machine.

Competition

Chat products and operator CLIs miss the team platform.

Model

Run it yourself. Keep the data. Bring your own model.

Open source. One Docker container on your machines, or Nakama Cloud if you do not want to operate it.

  • Privacy: chats, memory, and files stay on your volume. Nothing has to leave your network.
  • Your LLM: OpenAI, Anthropic, or open-weight models through Ollama or any OpenAI-compatible endpoint. Nakama is not the model vendor.
  • Cloud: same product, hosted — for teams that want the dashboard without running Docker.
